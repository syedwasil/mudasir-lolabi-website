# Er. Mudasir Lolabi — Official Website

Personal website for **Er. Mudasir Lolabi**, Chairman of RGPRS (Rajiv Gandhi Panchayati Raj Organization), Jammu & Kashmir — Indian National Congress.

## Site sections

- **Home** — hero with Shri Rahul Gandhi meeting photo, role, and quick links
- **About** — biography and responsibilities
- **Gallery** — portrait, meeting with Shri Rahul Gandhi, RGPRS meetings, field photos (click to enlarge)
- **RGPRS** — organization overview
- **Leadership & Initiatives** — vision and recent statements
- **Media** — press and social links
- **Connect** — personal profiles + RGPRS J&K official pages

## Deploy (GitHub + Vercel — free)

### 1. Push to GitHub

```bash
cd C:\Users\xb2k2\Projects\mudasir-lolabi-website
git init
git add .
git commit -m "Full chairman website with gallery and RGPRS sections"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/mudasir-lolabi-website.git
git push -u origin main
```

### 2. Vercel

1. Sign in at [vercel.com](https://vercel.com) with GitHub.
2. **Add New → Project** → import this repo.
3. No build command (static HTML).
4. **Deploy**.

Live URL: `https://your-project.vercel.app` — add a custom domain in Vercel when ready.
